### Задача: мини-страница «Чат с консультантом»

Одна страница `/chat` из двух частей:

1. **Список встреч пользователя** (мок-данные — см. ниже). Список должен рендериться
   **на сервере** (при выключенном JS в браузере он всё равно виден), но дальше жить через
   TanStack Query: кнопка «Обновить» перезапрашивает данные без перезагрузки страницы.
2. **Чат** поверх WebSocket. Ниже — готовый echo-сервер на Node (запуск `node server.js`),
   он возвращает каждое сообщение с задержкой 300 мс и **раз в ~30 секунд рвёт соединение**.

Требования к чату:

- Отправленное сообщение появляется в ленте сразу, до ответа сервера.
- **Если соединение оборвалось** — пользователь это видит (статус «нет связи»), а
  неотправленные сообщения помечены и не теряются: после восстановления связи уходят
  сами или по кнопке «повторить».
- Переподключение автоматическое, без перезагрузки страницы.
- Достаточно одного «собеседника», без авторизации и истории на сервере.

```js
// server.js — запускать: node server.js (порт 8081)
const { WebSocketServer } = require('ws'); // npm i ws
const wss = new WebSocketServer({ port: 8081 });
wss.on('connection', (ws) => {
  ws.on('message', (m) => setTimeout(() => ws.readyState === 1 && ws.send(m.toString()), 300));
  setTimeout(() => ws.terminate(), 25000 + Math.random() * 10000);
});
```
